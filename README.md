# Adeptus Statisticus

![Adeptus Statisticus favicon](favicon.webp)

Sanctification of probability. Cogitation of W40K unit statistics. Reverence to the Omnissiah.

## Sacred Relics

- `index.html`: the blessed interface and unit stat forms.
- `styles.css`: the archeo-stylisation rites.
- `favicon.webp`: the Cult Mechanicus sigil.

## Invocation

Open `index.html` in a browser, or awaken a local static server:

```sh
python3 -m http.server
```

Then consult the cogitator at `http://localhost:8000`.

## Benediction

Dark panels, brass seals, red lumens, inline inputs, and responsive rites for both desktop shrine and mobile reliquary.
